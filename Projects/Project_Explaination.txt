Steps Of Project

Step No. 01: Table and TMG creation

Create the tables which are ZEMP_MASTER_MY and ZEMP_LEAVE_MY with the respected fields.

MASTER TABLE NAME	ZEMP_MASTER_MY
LEAVE TABLE NAME	ZEMP_LEAVE_MY


Then create the TMG for maintain the records of the tables.

TMG FOR MASTER TABLE	ZEMP_MASTER_MY
TMG FOR LEAVE TABLE	ZEMP_LEAVE_MY
